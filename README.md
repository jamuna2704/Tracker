# 🌱 Jamuna's Growth Tracker

A personalized productivity and self-growth dashboard designed to help students track learning, health, finance, academics, and career preparation in one place.

The application acts as a digital growth companion where users can monitor daily habits, coding progress, study goals, and long-term development.

---

## ✨ Features

## 🏡 Growth Dashboard
- Daily motivational greetings
- Personal focus period tracking
- "Why I am doing this" reminder
- Productivity metrics overview
- 7-day consistency heatmap
- Growth tree visualization
- DSA and ML progress charts
